HeroCards Style Guide

Surface materials, emotional color system, texture language, motion personality, and screen identity for a premium mobile card game.

Design Philosophy

HeroCards is built on a void-black stage where every pixel of color is earned. The UI is not a flat dark theme — it is a world made of physical materials: brushed dark metal panels, holographic foil cards, frosted glass overlays, cracked obsidian battle arenas. Light does not illuminate surfaces evenly; it bleeds through cracks, pulses along edges, and erupts during moments of power.

Three emotional registers define the visual language:

  • Neon Mint — the heartbeat of interaction. Buttons, progress, navigation, active states. Cool, precise, always-on.
  • Electric Violet — raw power moments. Legendary reveals, level ups, achievement earned, XP rewards, critical abilities. Violet is the emotional spike.
  • Forge Gold — value and prestige. Currency, premium rewards, legendary rarity accents, store highlights, rank achievements. Gold communicates worth.

The app is never still. Even at rest, energy flows through panel borders, cards breathe with faint scale pulses, and ambient particles drift behind headers. Stillness is death — life is motion. Every screen has its own visual temperature and signature, so navigating the app feels like moving through distinct zones of a living world.

ALL TEXT IS WHITE OR LIGHT — NEVER GRAY ON DARK BACKGROUNDS, WHICH IS UNREADABLE.

Surface Materials

Every surface in HeroCards is a material, not a color. Materials have texture, edge behavior, light response, and physical weight. A panel should feel like you could touch it.

Brushed Dark Metal
The primary panel material. Subtle directional grain with noise texture creates a tactile, industrial feel. Used for every standard panel, card, modal, and list container in the app.
Used by: panels, cards, modals, quest rows, list containers, bottom sheets
Layer Stack (bottom → top)
1. Base gradient LinearGradient View
2. Noise texture Image (tiled PNG)
3. Brush grain Image (tiled PNG)
4. Content children
Implementation Recipe
// Wrapper component — use instead of plain View for all panels
<View style={[styles.panel, style]}>
  {/* Layer 1: Base gradient */}
  <LinearGradient
    colors={['#0c0d14', '#0a0b10']}
    style={StyleSheet.absoluteFill}
  />

  {/* Layer 2: Noise texture — tiled 64x64 PNG, fractal noise */}
  <Image
    source={require('../assets/textures/noise-64.png')}
    style={[StyleSheet.absoluteFill, { opacity: 0.04 }]}
    resizeMode="repeat"
  />

  {/* Layer 3: Horizontal brush grain — tiled 128x4 PNG */}
  <Image
    source={require('../assets/textures/brush-grain-128x4.png')}
    style={[StyleSheet.absoluteFill, { opacity: 0.02 }]}
    resizeMode="repeat"
  />

  {/* Layer 4: Content */}
  {children}
</View>

// styles
panel: {
  borderRadius: 14,
  borderWidth: 1,
  borderColor: '#1e2030',
  overflow: 'hidden',
  padding: 16,
}
Texture assets needed:
• noise-64.png — 64×64 fractal noise grayscale PNG. Generate in Photoshop: Filter → Noise → Add Noise (Gaussian, 40%, mono) on solid gray.
• brush-grain-128x4.png — 128×4 horizontal grain PNG. Generate: 1px white lines at 3% opacity on transparent, spaced 2–3px apart.
• Both use resizeMode="repeat" which tiles the image across the full View. RN's Image component handles this natively on iOS.

Holographic Foil
Prismatic surface that shifts hue as the shimmer sweep passes. The foil effect is entirely Skia-driven — a LinearGradient with animated offset creates the color shift, while a noise layer adds foil grain.
Used by: HeroCard shimmer (Rare+), legendary card borders, reward banners, premium badge backgrounds
Layer Stack (inside Skia Canvas)
1. Card base Skia RoundedRect
2. Shimmer gradient Skia LinearGradient
3. Foil noise grain Skia Image (tiled)
4. Hue rotation pass Skia ColorMatrix
Implementation Recipe (Skia)
// Inside <Canvas> on HeroCard — this is the shimmer/foil layer
// Runs ONLY for Rare, Epic, Legendary cards

// Animated shared value drives the sweep position
const shimmerX = useSharedValue(0);
useEffect(() => {
  shimmerX.value = withRepeat(
    withTiming(1, {
      duration: shimmerSpeed, // Rare=2000, Epic=1500, Legendary=1200
      easing: Easing.inOut(Easing.ease),
    }),
    -1, // infinite
    true  // reverse
  );
}, []);

// Layer 2: Shimmer gradient sweep
<Rect x={0} y={0} width={300} height={433}>
  <LinearGradient
    start={vec(shimmerX.value * 600 - 200, 0)}
    end={vec(shimmerX.value * 600, 433)}
    colors={[
      'transparent',
      'rgba(177, 78, 255, 0.06)', // violet tint
      'rgba(255, 255, 255, 0.12)', // white highlight
      'rgba(0, 255, 170, 0.06)',   // mint tint
      'transparent',
    ]}
  />
</Rect>

// Layer 3: Foil noise grain (reuse noise-64.png)
<Image
  image={noiseImage}
  x={0} y={0}
  width={300} height={433}
  fit="repeat"
  opacity={0.04}
/>

// Layer 4: Hue rotation (Legendary only)
// Rotates the entire shimmer hue over time for prismatic effect
<Group layer={
  <Paint><ColorMatrix
    matrix={hueRotationMatrix(hueAngle.value)}
  /></Paint>
}>
  {/* shimmer layers above */}
</Group>
Rarity-specific behavior:
• Rare: single sweep direction, 2s cycle, no hue rotation
• Epic: dual sweep (two gradient passes, 90° offset), 1.5s cycle, no hue rotation
• Legendary: dual sweep + continuous hue rotation (full 360° over 6s) + particle edge dots
Performance: Skia renders on GPU. The shimmer is a single <Rect> with animated gradient positions — very cheap. Hue rotation uses a ColorMatrix filter which is also GPU-native. Total overhead: <1ms/frame.
Cracked Obsidian
Volcanic dark surface with faint red fissure lines glowing beneath. Heavy, ominous, and hot. Used exclusively for battle and combat contexts — the visual shift signals danger.
Used by: BattleScreen background, damage flash overlays, boss encounter UI, forfeit confirmation modal
Layer Stack (bottom → top)
1. Dark base gradient LinearGradient View
2. Heavy noise Image (tiled PNG)
3. Fissure crack lines Skia Path + glow
4. Red vignette pulse Animated View
5. Content children
Implementation Recipe
// BattleScreen background wrapper

{/* Layer 1: Dark warm base */}
<LinearGradient
  colors={['#08060a', '#0d0810']}
  style={StyleSheet.absoluteFill}
/>

{/* Layer 2: Heavy noise (higher opacity than Brushed Metal) */}
<Image
  source={require('../assets/textures/noise-64.png')}
  style={[StyleSheet.absoluteFill, { opacity: 0.05 }]}
  resizeMode="repeat"
/>

{/* Layer 3: Fissure crack lines — pre-rendered PNG overlay */}
// Option A (simple): A pre-rendered 375x812 PNG of red crack
// lines on transparent. Fastest, no Skia overhead.
<Image
  source={require('../assets/textures/obsidian-cracks.png')}
  style={[StyleSheet.absoluteFill, { opacity: 0.06 }]}
  resizeMode="cover"
/>

// Option B (dynamic): Skia Path for animated crack glow
<Canvas style={StyleSheet.absoluteFill}>
  <Path
    path={crackPath} // pre-defined SVG path string
    color="transparent"
    style="stroke"
    strokeWidth={1.5}
  >
    <Shadow dx={0} dy={0} blur={6}
      color="rgba(255, 71, 87, 0.3)" />
  </Path>
  <Path path={crackPath}
    color="rgba(255, 71, 87, 0.15)"
    style="stroke" strokeWidth={0.5} />
</Canvas>

{/* Layer 4: Red vignette — pulses during combat */}
<Animated.View style={[StyleSheet.absoluteFill, {
  background: 'radial-gradient(...)' // not supported in RN
}]} />
// Use expo-linear-gradient with radial approximation:
// A centered radial vignette = transparent center + dark red edges
// Animate opacity with Reanimated: 0.3 → 0.5 over 3s loop
const vignetteOpacity = useSharedValue(0.3);
useEffect(() => {
  vignetteOpacity.value = withRepeat(
    withTiming(0.5, { duration: 3000 }),
    -1, true
  );
}, []);
Texture assets needed:
• noise-64.png — same asset as Brushed Metal, just at higher opacity (0.05)
• obsidian-cracks.png — 375×812 (iPhone screen) red crack lines on transparent. Generate in Photoshop/Illustrator: jagged branching paths in #FF4757 at 15% opacity, 1–2px stroke. Or use Skia Path (Option B) for animated glow.
Recommended: Option A (PNG) for the static cracks + Skia Shadow on a simplified Path for the animated glow during damage events. This gives you the best of both: cheap static texture + dramatic animated glow when hits land.
Shared texture assets: All four materials share noise-64.png. Only Brushed Metal adds the brush-grain-128x4.png. Only Cracked Obsidian adds obsidian-cracks.png. Total new assets: 3 small PNGs (<10KB combined). Store in assets/textures/.

Texture Language

Textures prevent the UI from feeling like flat CSS divs. Every texture serves a purpose — grain adds physical tactility, scan lines add sci-fi atmosphere, hex grids suggest technology, and circuit traces imply connectivity.

Film Grain Noise
3–5% opacity. All Surface + Elevated layers.
Scan Lines
Faint horizontal lines + sweeping gradient. Headers, battle UI.
Hex Dot Grid
2–3% opacity dot pattern. Career screen, collection vault.
Circuit Traces
Faint grid lines with junctions. Store screen, tech-type backgrounds.
Diagonal Hatch
Angled lines at 135°. Caution zones, locked content, disabled states.
Obsidian Fissures
Red crack lines on dark volcanic surface. Battle backgrounds only.
Rule: No texture should be clearly visible at normal viewing distance. If you can distinctly see the pattern, dial it back. Textures create a subliminal sense of material, not a visible overlay.

Layered Glow System

On OLED screens, traditional drop shadows vanish against near-black. Instead, every emphasis effect uses a three-layer glow stack: a tight inner core, a medium halo, and a wide ambient bloom. Single box-shadows look flat; layered glows look radiant.

MINT
Interactive Glow
Buttons, progress, active nodes, selected items
VIOLET
Power Glow
Rewards, level up, legendary, achievements
GOLD
Value Glow
Currency, store, legendary borders, premium
DANGER
Damage Glow
HP critical, damage dealt, errors
VITAL
Health Glow
HP healthy, success, healing, completion
Three-layer formula:
0 0 4px {color}aa — tight core (inner edge definition)
0 0 16px {color}66 — medium halo (visible glow ring)
0 0 40px {color}22 — wide bloom (ambient atmosphere)
Scale all three radii proportionally for larger/smaller elements. For maximum-drama moments (legendary reveal, level up), add a fourth layer: 0 0 80px {color}11 for environmental wash.

Rarity Visual Tiers

Each rarity tier has escalating visual treatments. Higher rarity = more visual energy. The card should feel increasingly alive as rarity increases.

Common
Static card, no effects. Clean brushed metal surface. The absence of effects makes rarer cards feel special by contrast. Material: Brushed Dark Metal only.
Uncommon
Subtle single-sweep shimmer (2s cycle), faint border glow (1-layer). The first hint of energy — a gentle pulse of light that says this card has a spark.
Rare
Dual-sweep shimmer (1.5s), animated foil grain, border uses 2-layer glow, gradient border shifts blue. The card catches light as if made of polished metal with a chrome finish.
Epic
Continuous shimmer + particle edges (floating dots along border), 3-layer glow, faint ambient energy particles around card bounds. The card feels energized — alive with contained power.
Legendary
Holographic prismatic shimmer with hue rotation, living gradient border (gold↔violet shift), 4-layer glow with environmental bloom, energy particle shower, screen-shake on reveal. The card is barely containing its own power.
Implementation: Shimmer uses Skia LinearGradient sweep. Particle edges use Reanimated + absolute-positioned dots. Holographic effect layers multiple gradient passes with hue rotation. Gradient borders use the dual background-clip technique. Screen shake uses Vibration.vibrate() + Reanimated translateX/Y jitter.

Elevation Drama

Elevation is a multi-property transformation — scale, glow intensity, border treatment, and background dimming all shift together. Each level adds more visual energy and physical presence.

Resting
scale(1.0) • flat border
Base state. No glow, no animation. Static and grounded.
Hovered
scale(1.02) • 2-layer glow
Subtle lift + faint accent glow. 200ms spring. Tappable cards, interactive list items.
Lifted
scale(1.05) • 3-layer glow + gradient border
Strong glow + gradient border shift. 300ms spring. Selected card, active element, card preview.
Heroic
scale(1.1) • 4-layer glow + particles + bg dim
Maximum drama. Full 4-layer glow halo, gradient border animates, particle ring, background dims. 500ms dramatic ease. Legendary reveal, featured card, boss encounter.
Implementation: Use Reanimated useAnimatedStyle with spring configs. Depth blur on background elements uses RN blurRadius on an overlay View. Particle ring is a Skia path animation around element bounds. Gradient borders animate via interpolating the gradient stops.

Ambient Life

A premium game UI is never fully still. Even at rest, the world breathes. These idle-state animations run continuously at low intensity, creating a subliminal sense of a living interface. They should be subtle enough to be felt, not watched.

Border Energy Flow
A slow gradient pulse travels along panel top edges. Mint blends into violet. Creates a sense of power flowing through the UI.
4s linear infinite • Top border of key panels only • opacity 0.3–0.5
Card Breathing
Cards in grids/hands have a faint scale pulse: 1.0 → 1.005 → 1.0 over 3s. Barely perceptible, but makes the collection feel alive rather than a static grid.
3s ease-in-out infinite • scale amplitude 0.5% • Stagger start times per card
Glow Pulse
Active buttons and progress fills slowly modulate their glow radius: tight core steady, outer bloom breathes 0.3–0.6 opacity over 2s. Creates a heartbeat rhythm.
2s ease-in-out infinite • Only the outermost shadow layer pulses • Primary action buttons, progress fills
Particle Drift
2–4 faint particles drift slowly upward behind screen headers. Tiny dots (2–3px) at 0.1–0.2 opacity. Colored to match the screen's accent (mint for most, violet for Career, gold for Store).
8–15s travel time • Reanimated translateY • randomized X, size, opacity • max 4 particles at once
Shimmer Sweep
A very faint diagonal light sweep passes across the screen title text every 6s. Like light catching a metallic surface. Applies to Orbitron screen titles only.
6s linear infinite • 45° gradient mask • 0.05 opacity • Skia or RN MaskedView
Background Vignette Pulse
Screen backgrounds have a radial vignette that subtly breathes, expanding and contracting the dark edges. Creates depth without any moving elements.
5s ease-in-out infinite • radial-gradient center opacity 0 → 0.03 • edges rgba(0,0,0,0.4–0.5)
Performance rule: Ambient animations should use useNativeDriver: true or Reanimated shared values exclusively. Never animate layout properties (width, height, padding) for ambient effects — only transform and opacity. Total ambient animation count per screen: max 6 simultaneous.

Micro-Interactions

Every touchable element should respond with more than a scale bounce. These micro-interactions layer together to create a UI that feels physically responsive — like operating real controls in a cockpit, not tapping flat rectangles.

Button Shimmer
Trigger: idle primary buttons
A diagonal light sweep passes across the button surface every 3s. Creates a "catch the light" effect that draws the eye to available actions. The sweep is a 60% width gradient mask moving left to right.
Press Ripple
Trigger: onPressIn on any interactive surface
scale(0.96) + glow contracts to tight core only + a radial ripple emanates from the touch point (0.1 opacity, expands over 300ms, then fades). The ripple color matches the element's accent.
Glow Trail on Drag
Trigger: drag gesture on cards
As a card is dragged (e.g., battle attack gesture), it leaves a faint trailing glow in its wake. The trail is 3–4 positions behind, each at decreasing opacity (0.3, 0.2, 0.1). Color matches the card's type color.
Success Burst
Trigger: quest complete, achievement earned, card collected
A rapid particle burst (8–12 particles) explodes outward from the element using the Burst motion type. Particles are small (3–5px) circles in the accent color, travelling 30–60px outward over 400ms, fading to 0. Paired with a haptic tap.
Number Tick-Up
Trigger: coin/XP value changes
Numbers don't jump — they rapidly tick through intermediate values over 300–500ms. Each digit rolls like an odometer. The text glows briefly at the final value (matching accent: gold for coins, violet for XP, mint for stats).
Tab Switch Energy
Trigger: bottom tab navigation
When switching tabs, the active indicator doesn't just move — it leaves a brief energy trail between the old and new positions. The trail is a 2px line in mint that stretches, then snaps to the new tab and fades.

Wow Moments

Iconography

All icons from @expo/vector-icons (MaterialCommunityIcons). Use the filled variant by default — outlined icons feel thin against dark backgrounds.

Icon color rules:
• Primary context (headings, active labels) → #ffffff
• Muted context (inactive, hints) → #6e7191
• Interactive context (buttons, links) → #00FFAA
• Domain context (type icons on cards) → use the type color
• Sizes: 16px (inline), 20px (list items), 28px (tab bar, empty states)
ALWAYS USE ICONS (MaterialCommunityIcons or custom) — NEVER EMOJIS. Emojis render inconsistently across devices and do not support color theming.
